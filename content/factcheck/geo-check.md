# historical-basemaps check

Generated by `tools/check_geo.py` on 2026-11-21 (16 s, grid 0.5°, blocks from 40,000 km²). Read-only: it changes no data.

Compares the atlas with the 47 historical-basemaps world snapshots from 3000 BCE to 2010. The snapshots are hand-drawn and mostly marked approximate before 1700, so each row is a lead to check against a published source. Snapshot peoples and ways of life (hunter-gatherers, cultures, tribes) are left out. Atlas realms are linked to snapshot polities by shared land, so a different name for the same state is not a mismatch.

Source: A. Ourednik, historical-basemaps (GPL-3.0), https://github.com/aourednik/historical-basemaps.
